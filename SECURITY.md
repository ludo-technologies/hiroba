# Security Policy

## Reporting a vulnerability

Do not open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/ludo-technologies/hiroba/security/advisories/new),
or e-mail contact@ludo-tech.org.

Include the Hiroba version, whether the issue affects the client, the server,
or the hosted edition at hirobaoffice.com, and steps to reproduce.

You will get an acknowledgement within 3 business days. Fixes ship as a new
release and are credited in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release is supported. Hiroba updates itself in place, so
staying current requires no action.
